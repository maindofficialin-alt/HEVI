# HEVAI — AI-Powered Dashboard Intelligence

A premium, cinematic website for **HEVAI** — a company specializing in custom AI dashboards, intelligent platforms, and operational intelligence solutions.

## 🚀 Live

Deployed on [Vercel](https://vercel.com).

## ✨ Features

- **Glassmorphic Design** — Frosted glass cards on a cyan-lavender gradient
- **Interactive Particles** — Canvas-based particle system with mouse repulsion
- **Scroll Reveals** — IntersectionObserver-powered section animations
- **3D Tilt Effects** — Perspective transforms on service cards
- **Counter Animations** — Animated statistics with eased counting
- **Responsive** — Mobile-first, adapts to all screen sizes

## 🎨 Design System

| Token | Value |
|-------|-------|
| Background | Cyan-Lavender gradient (`#d4f1f9` → `#e0d4f5`) |
| Primary | Crimson `#e60026` |
| Secondary | Teal `#0891b2` |
| Tertiary | Purple `#7c3aed` |
| Typography | Geist + JetBrains Mono |

## 🛠 Local Development

```bash
npx serve .
```

## 📦 Deploy to Vercel

1. Push to GitHub
2. Import repo in [vercel.com/new](https://vercel.com/new)
3. Framework: **Other** (static site)
4. Deploy ✅
